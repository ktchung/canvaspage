# Source

## Rules

- All runtime state lives in the Zustand store (`store/index.ts`). No localStorage, no IndexedDB, no other persistence.
- Images are blob URLs. Always `URL.revokeObjectURL()` when deleting images to prevent memory leaks.
- Layout math (grid cells, masonry columns, z-order sorting, crop-aware dimensions) lives in `store/index.ts` as exported helpers (`cellMetrics`, `masonryMetrics`, `fitToCell`, `pointToCell`, `imageCell`, `effectiveDims`, `sortByZ`, `makeId`). Reuse them instead of re-deriving geometry in components.

## Routing

TanStack Router with file-based routes in `routes/` and hash history (`main.tsx`). `/` redirects to `/editor`. `routeTree.gen.ts` is generated by the Vite plugin — don't edit it by hand.

## Canvas editor

Built with react-konva. Canvas images are Konva `Image` nodes on a `Stage`; the page is 794×1123 canvas units (A4 at 96 dpi).

- Each `DocumentPage` has its own `settings`: auto-align mode (`off` | `grid` | `masonry`), rows, columns, margins and gap. Grid and masonry pages reflow automatically when settings change.
- Images can be cropped; `CanvasImage.crop` is in source-image pixels. Use `effectiveDims()` for the visible aspect ratio.
- PDF export (`lib/exportPdf.ts`) rebuilds each page on an off-screen Konva stage from store data, rasterises it to PNG (`pixelRatio: 2`) and places it full-page with pdf-lib. Don't use a DOM-capture approach (html2canvas is avoided by design).
- Add images to a page with `placeImageOnPage()` (`lib/placeImage.ts`); it loads the natural size, applies the page's auto-align rules and toasts on rejection.
- `lib/konvaHitFix.ts` replaces Konva's colour-based hit detection with geometric hit testing, because browser canvas-fingerprinting protection adds noise that breaks it. Don't remove it.

## Component library

Shadcn/ui components with Tailwind v4 utilities. Prefer existing Shadcn primitives over custom markup.

## Icons

Custom SVG icons live in `src/assets/icons/`. Import them with Vite's `?raw` suffix (returns the file as a string at build time) and render via the generic `SvgIcon` component:

```tsx
import editorSvg from '@/assets/icons/editor.svg?raw'
import SvgIcon from '@/components/shared/SvgIcon'

<SvgIcon src={editorSvg} className="h-4 w-4" />
```

Size via Tailwind on the wrapper (`h-*`/`w-*`). Use `fill="currentColor"` in new icons so they inherit CSS color (`all-images.svg` has a fixed fill). Use lucide-react for generic/utility icons not covered by the custom set.

## Toasts

Use `showToast(variant, title, description)` from `components/shared/ToastCard.tsx` (variants: `success`, `error`, `warning`). It renders a `ToastCard` through sonner's `<Toaster>` mounted in `routes/__root.tsx`.
